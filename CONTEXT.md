# Chaos: Task Routing

Pick the workspace for the task, then read only that workspace's CONTEXT.md.

| Task Type | Go To | Description |
|-----------|-------|-------------|
| Literature | `workspaces/literature-review/CONTEXT.md` | Search, verify, synthesize, promote into the bibliography |
| Library module | `workspaces/module-build/CONTEXT.md` | Spec, tests, code, verification, integration |
| Study | `workspaces/study/CONTEXT.md` | Preregister, run, analyze, report |
| Paper | `workspaces/paper/CONTEXT.md` | Outline, draft, review, finalize |
| Workspace structure | `workspaces/workspace-builder/CONTEXT.md` | Rebuild or extend this ICM structure |

## Shared Resources

| Resource | Location | Contains |
|----------|----------|----------|
| Shared references | `_config/CONTEXT.md` | Question, architecture, numerics, catalogs, bibliography, settings |
| Run-store schema | `schema/run-store.md` | HDF5 layout used by Julia and Python |
| ICM rules | `_core/CONVENTIONS.md` | Workspace conventions |
| What is built when | `_config/build-order.md` | Milestones M0-M8 |
| Machine and local GPU | `_config/environment.md` | Compute target, the GPU of the [local] criteria |
