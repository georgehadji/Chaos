# Bibliography

Verified references. Rules for keys and verification classes: `conventions.md`. Load the section file for the topic, not all of them.

| File | Holds |
|------|-------|
| `references.bib` | Every citable record (BibTeX); the canonical key list |
| `maps.md` | Maps and model systems |
| `indicators.md` | Chaos indicators (variational, Fourier/frequency, other) |
| `integrators.md` | Symplectic integrators and geometric integration |
| `solar-system.md` | Solar-system dynamics |
| `lyapunov.md` | Lyapunov-exponent algorithms |
| `benchmarks.md` | Benchmark values read in a cited source |
| `corrections.md` | Corrections made to the original seed list |
| `unverified.md` | Items that must not be cited |
| `conventions.md` | Key format, verification classes |
