# Bibliography Conventions

Layer 3, canonical. Used by literature-review/03 and /05.

## Key format

Family names (up to three authors, else the first author only) joined without spaces, then the year: `Chirikov1979`, `HenonHeiles1964`, `MacKayMeissPercival1984`, `Skokos2010`. A clash adds `a`, `b`: `Maffione2011a`. ASCII only (`Henon`, not the accented form).

## Verification classes

| Class | Meaning | Citable |
|-------|---------|---------|
| verified | DOI, arXiv or DataCite record fetched and matched (title, authors, venue, volume, pages) by script | yes |
| verified-secondary | No DOI; confirmed through independent reference lists or a registry record (e.g. ADS, INSPIRE) | yes, flagged |
| UNVERIFIED | Could not be confirmed | no; listed in `unverified.md` |

## Other rules

- A key marked `?` in a catalog is pending and must not be cited.
- Benchmark values enter `benchmarks.md` only when read in a cited source, with page, equation or table.
