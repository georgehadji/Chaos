# Value Types

Layer 3, canonical. Every study (study/01) and paper (paper/01) agrees which of these it delivers before work starts (ICM Pattern 13). At least one per study.

| Type | Delivers | Passes when |
|------|----------|-------------|
| NOVEL | A result not in the verified bibliography | prior-art check in `research-ideas.md` finds no match |
| REPRODUCES | Independent confirmation of a published value | value matches a `bibliography/benchmarks.md` row within the stated tolerance |
| FALSIFIES | A test that could fail a stated claim (C1-C3, R2 criteria) | the decision rule is preregistered before data |
| TOOL | Verified, reusable code other researchers can run | modules `verified`, documented, tagged release |
| NEGATIVE | A documented null or failed result | reported with the same rigour as a positive one |
