# Indicators

Chaos indicators as reducers: the Smaller Alignment Index SALI, the Fast Lyapunov Indicator FLI, the MEGNO, the Relative Lyapunov Indicator RLI with its pair start, and the stretching-number spectra `StretchingNumbers` (cumulative histograms of the per-handoff log growth of two deviation vectors, kept in a per-orbit workspace, with the spectral distance D, `stretching_range` and the run check `check_run`), their pure functions and the frame checks.
