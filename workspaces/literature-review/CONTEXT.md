# Literature Review

Find, verify and promote references for one topic per run.

## Task Routing

| Task Type | Go To | Description |
|-----------|-------|-------------|
| Plan a search | `stages/01-scope/CONTEXT.md` | stage 01 |
| Run and screen the search | `stages/02-search/CONTEXT.md` | stage 02 |
| Verify candidates | `stages/03-verify/CONTEXT.md` | stage 03 |
| Annotate papers (optional) | `stages/04-synthesize/CONTEXT.md` | stage 04 |
| Merge into the bibliography | `stages/05-promote/CONTEXT.md` | stage 05 |

## Shared Resources

| Resource | Location | Contains |
|----------|----------|----------|
| Shared references | `/_config/CONTEXT.md` | Canonical facts, catalogs, bibliography |
| Build order | `/_config/build-order.md` | Which slugs to run, in which milestone |
