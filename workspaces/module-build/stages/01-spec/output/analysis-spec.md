# Spec: analysis

Library layer: Analysis (new, proposed in P2) and Figures (`_config/architecture.md`, "Module map" row Figures and "Layering": above Experiments, which they may import; nothing below may import them). Created by decision D60 (proposed, to be recorded after the checkpoint, `_config/decision-log.md`). Draft for the 01-spec checkpoint, branch module/analysis. No Julia type, function or file name appears outside the Compute and Oracle sections, except the paths of input and output files in Scope (Pattern 10). Choices made here, not given by a source, are marked "(proposed)" with a one-line rationale; open points for the owner are P1 to P8 in Scope.

Notation. "The preregistration" is `workspaces/study/stages/01-design/output/p1-le-benchmark-preregistration.md` with Amendments A1 to A6 (hash in its header). Section names in quotes are its sections. P is the set of panel orbits of the panel file (controls included), S_D and S_L are its flagged subsets, h4 the two extra starts of the run block. N_1, N_long, N_B and n_H2 are the horizons and the evaluation step of the preregistration ("Metrics", "H2", "Label rules"). V = {L1, L3, L4, L4b, L5, L5b, L6, L9} (eight methods; L2 is not in V). B = V without L9 = {L1, L3, L4, L4b, L5, L5b, L6}. lambda_m(n) is the stored finite-time exponent (natural log per map step) of method m at the recorded step n. "Item" is one stored (orbit, run type) series of the run store. "Primary item" of an orbit and method is the item with tau = 1, perturbation size eps_0 = 1e-8 (L2 only), initial direction pi/4, Float64, coordinates lifted for V and wrapped for L2 (Amendment A5, item 1).

## Scope

- Catalog rows: none (not a catalog method or system). Scope is fixed by decision D60 (proposed) and by the preregistration, sections "Hypotheses", "Metrics" (with "Label rules"), "Analysis plan" and "Stopping rules". Prerequisites, all `verified` or delivered: the run store of `schema/run-store.md` (version 2) written by the Experiments module, the study manifest `workspaces/study/stages/03-run/output/p1-le-benchmark-manifest.json` (stage 03 accepted: 1363 of 1363 chunks ok), the panel file `workspaces/study/stages/02-panel/output/p1-le-benchmark-panel.toml`, the preregistration.
- What the module does. From the manifest, the store, the panel file and the preregistration it computes, with no AI and no human input, the items T1 to T7 and F1 to F7 of "Analysis plan", the decision of H1 to H5 by the frozen rules, the labels of D36 and D37, a list of every reading it had to choose and of every deviation from the frozen text, and the data behind every figure. It writes a tables file and figure files. It reads only. It owns no scientific threshold.
- Out of scope, stated so that nothing is built early: the findings text (study stage 04 step 2, a subagent), any analysis not listed in "Analysis plan" (it would be "exploratory" and is not built here), new runs, any change of the store, the manifest, the panel or the preregistration, detection-time indicators (P2 of the paper sequence), the paper and its figure style.
- Generic by construction: every threshold, count, horizon, set definition and reference value is an input read from a parameter table (E0). The module holds no study value in code.
- numerics-defaults.toml: reads `seed` (bootstrap stream). The three health multipliers (`orthogonality_tol`, `pairing_residual_tol`, `det_residual_tol`) act only through the flags already stored in the files (E14 test d). No new key.

### Open points for the owner at the checkpoint

- P1 Home of the thresholds. The preregistration has the thresholds only in prose and cannot gain a machine-readable block: its Amendment rule bars amendments once stage 03 produced data (it did), and a changed file hash would also break the `prereg_sha256` checks. The table in E0 is reviewed at this checkpoint. Alternative: constants in code (rejected: a second home that no check reads).
- P2 Structure. Proposed: a new library module Analysis (everything numeric: loading, labels, hypotheses, tables, the numbers behind each figure; no plotting dependency) in the layer below Figures, and Figures as a package extension that loads when CairoMakie is present, as CUDA is for the device path. The command `analyze` of `bin/chaoslab.jl` runs both when started under the verify environment (which has CairoMakie), and writes the tables only, with a "figures skipped" line and exit code 2, when CairoMakie is absent. One command regenerates everything (stage 04 audit "Regenerable"). Needs an architecture row for Analysis, a layering edge Experiments <- Analysis <- Figures, and a build-order row. Alternative: plotting in a `verify/` script that reads the Analysis output, as the portraits of the panel (experiments spec, owner decision P7); two commands then.
- P3 Horizon used for S_D orbits (E3, E10, E11). Proposed reading: the finite-time spread R(n) and the convergence time n_conv use the horizon-N_1 series of every orbit of P (arm main), so that W and S are compared on one horizon; lambda_ref and the labels use each orbit's longest Float64 horizon (N_long for S_D orbits, arm long), as "Metrics" says. The long series enter only through lambda_ref and the labels. Alternative: n_conv against N_long for S_D orbits.
- P4 Failing tests force both axes (E14). The preregistration says disagreement tests force "unresolved" on either axis, and its Stopping rules give "both labels". Proposed: any failing applicable test sets both axes to unresolved. Alternative: only the axis the test is about.
- P5 Rotation numbers and the precision comparison (E14). Proposed: the first-half rotation number is the frozen formula at N/2, the second-half one is (x_N - x_{N/2}) / (2 pi N/2); labels across the three precisions are compared at N_B = 1e6, the only horizon all three precisions share (BigFloat stops there). Alternative: each precision at its own horizon (not comparable for BigFloat).
- P6 H5 verdict and H5a. Proposed: H5a is computed from the per-precision labels before the ladder test forces unresolved (otherwise a disagreement would erase itself); the verdict of H5 is "supported" only if H5a, H5b and H5c all pass, and the three results are always reported separately. The preregistration states no combined rule.
- P7 Statistics (E12). Proposed: percentile bootstrap, resampling orbits with replacement inside the set; H3 resamples W and S independently and forms the ratio of the two medians; the band of F2 is pointwise over n; stream keyed by `seed` and a label (as the panel streams). Intervals for cells with fewer than 20 orbits are shown with the count and no verdict.
- P8 Figure content not fixed by the preregistration (E19). Proposed: F1 one orbit per populated cell, the first drawn (lowest draw index, a panel property, not a data property); F3 empirical distribution functions per design class and K; F4 stacked bars of unresolved shares per test; F5 quantile bands of the stored running maxima against the tolerance line; F7 paired differences against the primary value, in lambda at n_H2 and in log10 of n_conv. These are presentations of listed items, not new analyses.

E1. Item selection. For a panel orbit o and method m the primary item is taken from the arm that holds it: V methods from arm main (horizon N_1) and arm long (horizon N_long, S_D only); L2 from arms main_l2 and long_l2 (wrapped, Amendment A5). Items of other arms are used only where stated (E14 ladder and direction tests, E16, E13). Identical items of different arms are one item (experiments spec R1 item 3); the analysis finds an item by its content (orbit, method, precision, horizon, tau, eps, direction, coordinate mode), never by arm name.

E2. Recorded values. At a recorded step n of an item the analysis reads lambda_m(n) (first exponent for the QR family and L9; the second exponent is not used), the orbit point (lifted x, p; wrapped x, p with winding counts in wrapped mode), the running maxima of the stored diagnostics with their thresholds and first-exceedance steps, and the cost record. The axis order of `schema/run-store.md` ("Axis order") applies.

E3. Reference exponent (Metrics, "lambda_ref per orbit"): lambda_ref(o) = lambda_L5(N(o)) of the primary L5 item at the horizon N(o) = N_long for o in S_D and N_1 otherwise (P3).

E4. H1a (H1). Delta_QB(o) = max over B of lambda_m(N_1) minus the min over B. o passes H1a if Delta_QB(o) <= the H1a bound.

E5. H1b. o passes if |lambda_L9(N_1) - lambda_L5(N_1)| <= the H1b bound.

E6. H1c. o passes if |lambda_L2(N_1) - lambda_L5(N_1)| <= the H1c bound, L2 the primary wrapped item (Amendment A5 item 1: estimators are compared, never trajectories, K16).

E7. Orbit sets (Panel, "Eligible sets"; H2; H3). Design class is the panel attribute. E_ch = {class C orbits with K > 0} union {controls with positive analytic exponent (hyperbolic fixed points, Y5)}. W = {orbits with instability label "positive growth supported" (E14) in design class S or X at K > 0} union {such orbits of class C at K <= K_c}. S = {class C at K = 2 pi and K = 10} (the preregistration states no label condition for S, so none is applied; the count of S orbits whose instability label is not "positive growth supported" is reported). From E_ch, W and S the analysis removes orbits flagged "drift" or "excluded" (stored flags) and lists them in a table; a recomputation from the stored points (some recorded |p| above the drift bound) must give the same flag set (I4). W and S are disjoint; E_ch overlaps both. S_L and S_D are the panel flags.

E8. Pass fraction and decision (H1). For sub-rule j the fraction f_j = (number of orbits of E_ch passing j) / |E_ch|. H1 is SUPPORTED if f_a >= 0.98, f_b >= 0.98 and f_c >= 0.90 (the E0 values); FALSIFIED if any is below; "not decidable" with the count if |E_ch| is below the minimum eligible set. Failing orbits are listed with their metric. Fractions are also given per K (T2).

E9. Exact-exponent controls (H1, last sentence; Amendments A4 item 4, A5 item 3, A6). For every control with positive analytic exponent lambda_exact (read from the panel file) and every method m in V: dev_m = |lambda_m(N_1) - lambda_exact|. Controls with `control_scope` "bound" must satisfy dev_m <= the control bound of m (E0; L9 has its own); a violation is a defect report that blocks the analysis (Stopping rules, third bullet). Controls with scope "info" are tabulated with their deviations and never block. Controls with exponent zero are not checked. The analysis recomputes dev_m from the stored series and compares it with the stored `control_deviation` attribute (I4).

E10. Finite-time spread and H2 (H2). Delta_V(n) = max over V of lambda_m(n) minus the min, at a recorded step n of the horizon-N_1 items (P3). R(n) = Delta_V(n) / lambda_ref. n_H2 is a recorded step (20 points per decade). H2 is SUPPORTED if the median over W of R(n_H2) is >= 0.10 and the lower end of its bootstrap interval (E12) is >= 0.05; otherwise NOT SUPPORTED (the null is reported, NEGATIVE); "not decidable" if |W| is below the minimum. R(n) is reported for all recorded n (F2) and by K and design class as well as pooled.

E11. Convergence time and H3 (H3). For orbit o and method m in V, n_conv,m is the smallest recorded step n such that |lambda_m(k) - lambda_ref| <= 0.05 lambda_ref for every recorded k in [n, N_1] (k = N_1 is recorded, so the condition includes the last value); if even k = N_1 is outside the band, n_conv,m is undefined and set to N_1 and counted. n_conv(o) = max over V. The share of undefined values is reported. H3 is SUPPORTED if median_W(n_conv) / median_S(n_conv) >= 10 and the lower end of the bootstrap interval of the ratio (E12) is > 3; NOT SUPPORTED otherwise (NEGATIVE); "not decidable" if |W| or |S| is below the minimum. lambda_ref <= 0 makes the relative band empty: such an orbit is listed and counted as undefined.

E12. Bootstrap (H2, H3). For a set X of m orbits and a statistic g (median, or ratio of two medians), B resamples are drawn, each of m orbits with replacement; the interval is the 2.5 and 97.5 percentiles of the B values of g (type 7 percentile, linear interpolation; B is the E0 value). Stream: the first 8 bytes, big-endian, of SHA-256 over the UTF-8 text "chaoslab-analysis-1|<seed>|<label>" seed the generator, as the panel streams are keyed (experiments spec, the panel manifest `stream_rule`); the label names the statistic and the set ("H2/W", "H3/W", "H3/S", "F2/<class>/<K index>", and so on), so no result depends on the order of computation or on threads. For H3, W and S are resampled with separate labels and the ratio is formed pairwise.

E13. H4 (H4). From the items of arm h4_float64 (L1, L5, horizon 1e9) and h4_double64 (L5, horizon 1e8): lambda_L1(T) and lambda_L5(T) at T = 1e9 for the starts K = pi/2 and K = 2 pi. Pass at a K if both are within the tolerance of the reference (0.298 +- 0.01; 1.172 +- 0.02). H4 is SUPPORTED if both K pass; otherwise "did not reproduce" with the four numbers. Cross-check, no verdict: Double64 L5 at 1e8 next to Float64 L5 at 1e8 (a recorded step of the Float64 item). Comparators, no verdict: the ensemble mean over the C orbits of lambda_L5(N_1) at each K of the panel (drift and excluded orbits removed) next to the Shevchenko2014 fit of the K range (benchmarks.md rows: 0.1333 K for K < 1 (Eq. 25); 0.469 (K - 1.037)^(1/2) for 1.1 <= K < 4.4 (Eq. 26); ln(K/2) + 1/K^2 for K >= 4.4 (Eq. 26); a K outside these ranges has "no fit") and the Chirikov line ln(K/2) at K = pi/2, 2 pi and 10.

E14. Labels (Metrics, "Label rules"; decisions D36, D37). The label of an orbit is a pair (instability, structure) at the horizon N(o) of E3 (and at other horizons where a test says so). Define r(N) = N lambda_L5(N) / [(N/10) lambda_L5(N/10)] = 10 lambda_L5(N) / lambda_L5(N/10), with N/10 a recorded step.
 - Instability. "positive growth supported" if lambda_L5(N) >= 1e-4 and r(N) >= 5. "none detected on the tested horizon" if lambda_L5(N) < 1e-4 and r(N) < 5. Otherwise "unresolved" (including lambda_L5(N/10) <= 0, where r is undefined).
 - Structure. "periodic" only for the exact periodic points of the panel (control kind periodic) whose binary64 return residual after the known period is at most 1e-10: the torus distance between the stored point at the recorded step q (q the period, at most 6, so recorded) and the start. "quasiperiodic" if instability is "none detected" and |rho_1 - rho_2| <= 1e-7 with rho_1 = (x_{N/2} - x_0) / (2 pi N/2) and rho_2 = (x_N - x_{N/2}) / (2 pi N/2) from the lifted x (P5). "irregular" if instability is "positive growth supported". Otherwise "unresolved".
 - Tests that force both labels to "unresolved" (P4), each applicable only where its data exist: (a) ladder, on S_L only: |lambda_L5 Float64 - lambda_L5 Double64| or |lambda_L5 Double64 - lambda_L5 BigFloat| above delta_lad at N_B, or the labels (computed by the rules above at horizon N_B from each precision's own L5 item, P5) differ between precisions; (b) estimators, on every orbit: failure of E4 or E5; (c) direction, on S_D only: the label computed at N_1 from the L5 item of each of the five initial directions (arm directions; the primary direction from arm main) is not the same for all five; (d) diagnostics, on every orbit: the L5 item carries the stored flag "diagnostics exceeded" (pairing, determinant or orthogonality running maximum above the multiplier of `numerics-defaults.toml`, decided by the runner).
 - Orbits of chunks that failed twice (flag "excluded") have both labels "unresolved" and are excluded from every fraction (Stopping rules). The label table says which tests could be applied to each orbit.

E15. H5 (H5). On S_L: H5a = fraction of orbits whose two labels at N_B are the same at Float64, Double64 and BigFloat, computed from the per-precision labels before test (a) acts (P6); passes if >= 0.90. On P: H5b = fraction with either axis "unresolved" after all tests; passes if <= 0.30. Among orbits whose instability label is "none detected" (after all tests), H5c = fraction with structure "unresolved"; passes if <= 0.30. Each sub-rule is "not decidable" with its count if its set is below the minimum. If H5b or H5c fails the report states that the label scheme is not informative and D36 or D37 return to the owner (a design result). The verdict of H5 is SUPPORTED only if all three pass (P6).

E16. Reported without a decision rule (Analysis plan F5 to F7; "Reported without a decision rule"):
 - eps_pair(n), eps_det(n) and the orthogonality loss: the stored running maxima per method against the threshold in force, summarised by quantiles over the orbits of a method (F5).
 - Cost: thread seconds per orbit-step by method and precision from the cost record, and the ratio to L5 of the same precision (F6).
 - Sensitivity (F7): for orbits of S_D, the difference lambda_m(n_H2; level) - lambda_m(n_H2; primary) and log10 [ n_conv,m(level) / n_conv,m(primary) ] for the levels of tau (arm tau_sweep, methods L4 and L5), eps (arm eps_sweep, L2), direction (arm directions, L1, L5, L9) and coordinate mode (arm wrapped, all nine methods). An item that carries `breakdown_tau` is not a failure: it is a result of the sweep; its breakdown step and kind are tabulated and its later values are absent (Amendment A5 item 2).

E17. Input checks before any output (refusal rules, Stopping rules; experiments spec R7, R8). The analysis refuses, naming the cause and writing nothing, if: the manifest status is not "complete", or a chunk is neither "ok" nor final-failed; the preregistration hash by the SELF rule (Amendment A1 item 1) differs from its header value or from the manifest's `prereg`; the panel file hash differs from the manifest's; a chunk file listed in the manifest is missing, is marked `pilot`, is incomplete, has `schema_version` other than 2, or has a `chunk_hash` that differs from the manifest's; a store file is not in the manifest (the `stale` area is ignored); a used row holds a non-finite value (the blanked rows of a failed chunk are never read and never used); the parameter table has a missing or an unknown key.

## Algorithm

Pseudocode of the order of work. No step depends on a scientific result of a later step.

1. Read the parameter table, the preregistration, the panel file and the manifest. Run the checks of E17. Record in the output header: the hashes of all four inputs, the module version, the git SHA, the parameter-file hash.
2. Open each chunk file once; for every item of the plan read the series named by E1 and E2 into one table indexed by (orbit, method, precision, horizon, tau, eps, direction, coordinate mode). Keep the stored flags and attributes. Release nothing until step 8.
3. Per orbit of P: lambda_ref (E3); E4, E5, E6 values; Delta_V(n) and R(n) for all recorded n; n_conv,m and n_conv (E11); drift recomputation (E7).
4. Controls (E9). If a "bound" control violates its bound: write the defect report and stop. Otherwise continue; the "info" rows go to T2.
5. Labels (E14) with all tests; the per-precision labels are kept for E15.
6. Sets (E7) and decisions in the fixed order H1 (E8), H2 (E10), H3 (E11), H4 (E13), H5 (E15), each with the "not decidable" rule.
7. Cell summaries and the numbers behind the figures (E16, E19), bootstrap bands.
8. Write the tables file: header (step 1), T1 to T7 and the figure data tables with digests, then the list of readings chosen (every item marked "(proposed)" in this spec, one line each), the list of deviations (E20), and the list of exploratory items (empty). Then draw the figures if the plotting extension is loaded (P2). Re-check the hashes of the inputs (I2).

## Invariants

- I1 Frozen numbers only. Every number that decides a hypothesis comes from the parameter table (E0). Changing a table value changes only the outputs that use it.
- I2 Read-only. The store files, the manifest, the panel file and the preregistration have the same bytes after the run as before (hashes recorded in the header and re-checked at the end).
- I3 Determinism. The tables file is byte-identical on a second run with the same inputs, at any thread count; the figure digests are equal (the figure files themselves may differ in embedded metadata).
- I4 Cross-checks of stored facts. Recomputed drift flags equal stored drift flags; recomputed control deviations equal the stored `control_deviation`; the last recorded step of each item equals its horizon; every item has the grid steps that E14 needs (N/10, N/2, N, and 1 to 6 for periodic controls). A mismatch refuses the run (E17).
- I5 Order. H1 to H5 are decided in this order from the inputs only; a later decision never alters an earlier one. The only early stop is the control defect of E9.
- I6 Non-finite values never enter a statistic (E17).
- I7 Conservation of counts. Every panel orbit appears exactly once in T1 and exactly once in T6; the cell counts sum to |P|; every orbit removed from a set appears in the drop table with its reason; W and S are disjoint.
- I8 Status of items. Every output item is labelled confirmatory (listed in the "Analysis plan" table) or exploratory (everything else); the module produces no exploratory item.
- I9 A hypothesis whose eligible set is below the minimum is reported "not decidable" with the count and is neither a pass nor a fail.
- I10 Sums. Per cell, the label counts sum to the cell's orbit count after drops; the fractions of E8 and E15 are ratios of those counts and print with the counts.

## Compute

- Work: reading about 1363 HDF5 chunk files (475 MB), then arithmetic on at most 15569 series of 201 to 221 recorded steps (at most 0.3 GB) and bootstrap resampling (1e4 resamples of at most a few hundred orbits, per statistic and per recorded step for the F2 band). Nothing here is data-parallel on a scale that justifies a GPU. All of it runs on CPU (Architecture, "Compute": no GPU path is built or measured, so nothing to fall back from). CPU-versus-GPU tolerance: not applicable.
- Parallelism: threads over bootstrap statistics and over cells; reading of the files may be serial if the HDF5 library serialises it. Results do not depend on thread count (I3); each bootstrap stream is keyed by its label (E12).
- Memory: the series table plus bootstrap buffers; stated limit (proposed) 8 GB at 23 threads; time limit (proposed) 10 minutes wall on this machine for the real store. Both are measured at stage 04 and recorded; exceeding them is a finding for the owner, not a failure of the science.
- Layering and dependencies: Analysis imports Foundation and Experiments (store reading, run-block reading, SELF hash, panel reader) and the standard library for statistics; a test parses `using` lines and fails on an upward edge. Figures is an extension of the package for CairoMakie (weak dependency, `[extensions]`), loaded by `bin/chaoslab.jl` when the verify environment is active; Analysis never loads it.
- Command: `julia --project=verify bin/chaoslab.jl analyze <prereg> <manifest> <panel> <parameters> --out <dir>` plus `--help`; exit code 0 only when the tables are written and the figures are drawn, 1 on refusal, 2 when only the figures are missing (P2).

## Oracle

Independent checks, none of which uses the module's own reader or statistics.

- O1 Closed forms at K = 0 (regular orbits). The deviation (cos a, sin a) under the tangent map of the integrable map is (cos a + n sin a, sin a); lambda(n) = ln sqrt[(cos a + n sin a)^2 + sin^2 a] / n for every method (preregistration, Amendment A1 item 2; Skokos2010 Eq. (62), p.35: O(ln n / n)). For the 40 T orbits at K = 0 of the real store the stored lambda_m(n) of every method of V equals the closed form at every recorded n within 1e-9 (proposed: round-off of a sum of at most 1e7 logarithms of order one; measured at stage 04). The labels of those orbits (instability "none detected", structure "quasiperiodic" with rho_1 = rho_2 = p_0 / (2 pi) to 1e-12) follow in closed form too.

E26. Budget rule and growth ratio [M1, M2]. For a series row, n(b) is the smallest recorded step of the item that is not before b (an item with no such step refuses); n'(n) is the recorded step nearest to n / 10, a tie going to the larger step. The same budget therefore maps to different steps in items of different horizon. The recorded grid holds every step to 100, then 20 points per decade, plus the steps N / 10 and N / 2 of the horizon N. On the grids of the real store n(b_0), ..., n(b_9) are 200, 447, 891, 1778, 3548, 7079, 14125, 28184, 56234, 112202 for the items of horizon 10^7 and 10^6 (the tangent chain, L1), and 200, 447, 891, 1778, 3548, 7079, 14125, 28184, 51200, 102400 for the items of horizon 102400 (pair, stretching); the step used is reported (T2, P15). For a window row, the budget b_k is read at the window W = b_k / 2 (b_k / 2 must be an element of `windows`, else refuse): the row `W=<W>` of the stored table, which holds the pair [0, W), [W, 2W). Growth ratio of X in {LE, SALI, FLI, MEGNO} at n: r_X(n) = g_X(n) / g_X(n'), with g_LE(n) = n lambda_1(n), g_SALI(n) = -L(n) (column `SALI.L` is ln GALI_2 and negative; the sign change leaves the quotient of the preregistration unchanged and lets the rule "a non-positive denominator is undecided" read alike for all four; P16), g_FLI(n) = `FLI.fli`, g_MEGNO(n) = `MEGNO.Ybar20_1`. r_X(n) is undefined, and the verdict undecided, if g_X(n) or g_X(n') is not finite or g_X(n') <= 0.

E27. Verdicts [M2]. For orbit o, indicator X and budget index k the verdict c_X(o, k) is chaotic, regular or undecided, or "not applicable" when the orbit has no item of the spec. Table R1, as forms (the numbers are the keys of E22):

| SALI, FLI, MEGNO | r_X(n) at n(b) of the tangent chain | r_X >= `ratio_threshold` | r_X undefined |
| RLI | `RLI.RLI` at n(b) of the pair item | RLI >= `rli_threshold` | not finite |

| E2 | D_E2, column `D`, row `W=b/2` | D_E2 >= `e2_d_threshold` | flag `undefined window` set, or D not finite |

A verdict that is neither chaotic nor undecided is regular. The flags below_floor, near_zero, mirror, tie, refined, near_pi and reldig_undefined do not change a verdict; their counts are tabulated (T16). Table R2 (sensitivity, T10) changes the rule of four indicators and of no other: LE chaotic iff n lambda_1(n) >= `r2_le_factor` ln n; SALI chaotic iff `SALI.sali`(n) <= `r2_sali_threshold`; FLI chaotic iff `FLI.fli`(n) >= `r2_fli_factor` ln n; MEGNO chaotic iff `MEGNO.Ybar20_1`(n) >= `r2_megno_threshold`; each undecided iff the value is not finite; E1, E2, WBA and RLI keep their R1 rule. "Verdicts" without qualification means R1; T10 names R2.

E28. Stable verdict, detection time, outcomes [M4]. For an orbit o of E_all (rho in {C, R}) and an indicator X in I_8 that has an item for o, the verdict series is c_X(o, k), k = 0 to 9. The verdict is stable from k iff b_k <= N_c / `persist_divisor` and c_X(o, j) is decided and equal to c_X(o, 9) for every j = k to 9 (so c_X(o, 9) must be decided). The detection time t_det(X, o) is b_k for the smallest k from which the verdict is stable, and is undefined if there is none. Outcome: correct iff t_det is defined and (c_X(o, 9) = chaotic and rho = C, or c_X(o, 9) = regular and rho = R); wrong iff t_det is defined and the verdict at k = 9 is the other class; undetected iff t_det is undefined (this includes c_X(o, 9) undecided). Censored detection time t~(X, o) = t_det for a correct outcome and `censor_factor` x N_c for a wrong or undetected one. M_X(A) is the median of t~(X, o) over the orbits of A that have an item of X. Reported for every X and set: M_X, the shares of the three outcomes, and the distribution of t_det where defined (T4, T5, F2). With the real parameter values t~ takes only the values b_0, ..., b_7 and 2 N_c (derived).

E29. Sets [Panel, "Eligible sets"; M8].
 - Controls are the orbits of P with the control flag. Dropped orbits: the controls; the orbits that carry the stored flag drift or excluded on any item (listed with the reason; on the real store only control 881 carries drift); the orbits with rho = U (counted by source and K).
 - E_all = (P union G) minus the controls, the flagged orbits and the orbits with rho = U.
 - For o in E_all with rho = C: S2 iff lambda_ref(o) >= `s2_lambda_min`; T_s iff lambda_ns(o) <= `f_s` lambda_ref(o); W2 iff lambda_ref(o) <= `w2_lambda_max` or o is in T_s. So T_s is a subset of W2; S2 and W2 can overlap, only through T_s; the size of the overlap is reported in T1 (P18).
 - T_s^design = the orbits of P in E_all with design class S and rho = C. Regular set = the orbits of E_all with rho = R.
 - E8 = the orbits of E_all that are in S_L or in G (the orbits that carry RLI). A set restricted to E8 is written with the suffix 8 (W2_8 is W2 intersected with E8). S_D* is S_D intersected with E_all, S_L* is S_L intersected with E_all.
 - Gate set = the orbits of P with K index `gate_k_index` that are not controls and whose design class is in `gate_classes`. Its size must equal `gate_size` (else refuse). It is not intersected with E_all (the gate tests the rule on orbits regular by construction, not the labels; P26).
 - A set with fewer than `min_set` orbits is "not decidable" for every statistic that is computed on it (E32); its count is reported. Every set size by source and by K value is in T1.

E30. Agreement and divergence [M6]. For a set A, a budget index k and indicators X, Y let D_XY(A, k) be the orbits of A decided for both at k. Contingency counts n_cc, n_cr, n_rc, n_rr of D_XY (first index the verdict of X, c chaotic, r regular), N their sum. A_XY(A, k) = (n_cc + n_rr) / N (undefined if N = 0). Cohen's kappa: p_o = A_XY, p_e = [(n_cc + n_cr)(n_cc + n_rc) + (n_rc + n_rr)(n_cr + n_rr)] / N^2, kappa_XY = (p_o - p_e) / (1 - p_e) if p_e < 1 and 0 if p_e = 1 (undefined if N = 0). For an indicator set I (I_7 or I_8): U(A, k, I) is the fraction of the orbits of A that are decided for every X in I at k whose verdicts are not all equal (the orbits dropped for an undecided verdict, or for a missing item, are counted and reported); A_min(A, k, I) is the minimum of A_XY(A, k) over the unordered pairs of I (21 pairs for I_7, 28 for I_8); the mean kappa is the mean of kappa_XY over the same pairs. The Spearman correlation of X and Y on A at k is the Pearson correlation of the midranks (ties get the mean of the ranks they occupy) of the chaos scores of E31 over the orbits of A with a score for both; it is undefined if fewer than 3 orbits or if either rank vector is constant (P33). A pair that involves RLI uses the orbits of A that carry RLI.

E31. Chaos scores, AUC, regular range [M7, M10]. The chaos score s_X(o, k) of E27's readings, oriented so that a larger score means more chaotic: LE r_LE; SALI r_SALI; FLI r_FLI; MEGNO r_MEGNO; RLI log10 of `RLI.RLI` (the value 0 gives minus infinity, which is kept: ranks only); E1 D_E1; E2 D_E2; WBA minus dig_min; STR minus log10 of `stretching.D` at n(b) of the stretching item (D <= 0 or not finite gives no score). A score is available iff the corresponding value is defined (an undecided verdict from a flag or a non-finite value gives no score) and it is finite, or minus infinity for RLI. AUC(X, k, K) for a K value: let C_K and R_K be the orbits of E_all with rho = C and rho = R at that K (panel and grid pooled) that have an available score; AUC = (1 / (|C_K| |R_K|)) sum over c in C_K, r in R_K of [1 if s_c > s_r, 1/2 if s_c = s_r, 0 otherwise]; it is computed (and reported, not decisive) only if |C_K| and |R_K| are both at least `min_set`, and then also by source if both counts are; STR is included (P32). Regular range of X at K and budget index k: the interval from the `range_lower_percentile`-th to the `range_upper_percentile`-th percentile (type 7) of the available scores of the orbits of the regular set at that K (panel and grid pooled), computed if at least `min_set` such orbits exist. For an orbit of T_s at that K: its leaving budget is b_k for the smallest k such that its score is above the upper percentile of the regular range of the same budget for every later index up to 9 (undefined if there is none; the count of such orbits is reported); and the second quantity is the share of the T_s orbits at that K whose score at k = 9 is below the median of the available scores of the regular set at that K. Both are reported with no rule, for X in I_7 and STR (P25).

E34. Bootstrap [M8; E12 reused, not respecified]. Resamples `bootstrap_resamples`, level `bootstrap_level`, seed `bootstrap_seed`. For a set A of m orbits listed in increasing orbit id and a label, replicate r = 1 to B draws m indices uniformly with replacement from the stream of the label in the order of E12 and computes the statistic on the resampled orbits (an orbit drawn twice counts twice). All statistics that share a label share the draws of the replicate: the seven M_X of Q, the seven F_X of F_med, the seven phi_X of Delta_phi, the 21 or 28 A_XY of U and A_min (joint resampling; P20). The interval of a statistic is the pair of percentiles (1 - level) / 2 and 1 - (1 - level) / 2 of its B replicate values (type 7, E12). A replicate on which the statistic is undefined is dropped and counted; if more than 5 percent are dropped, the interval is undefined and the decision of that hypothesis is NOT DECIDABLE (proposed, P20). The label is the text `p2|<item>|<set>|<set rule>|<verdict rule>|<variant>` with item in {H1, H2, H3, H4, H4design, H5}, set the name of the resampled set (for H3 two labels, one with W2 and one with S2: the two sets are resampled independently and the ratio is formed replicate by replicate), set rule in {E_all, E8}, verdict rule in {R1, R2}, variant in {all, minus-<X>}. Intervals are computed for the statistics named in E32 on the pooled sets only; the by-source and by-K rows of the tables carry counts and point values (P20).

### Algorithm (amendment)

Pseudocode of the order of work for study `p2-indicators`. No step depends on a scientific result of a later step.

1. Dispatch (E21). Read the parameter table (E22) and apply its two checks; read the preregistration (header hash, both run blocks), the manifest, the panel file; run the checks of E36 a to f and l, and take the SHA-256 of every input file, including the P1 reference inputs. Record the header of E37.
2. P1 reference. Run the labelling of the base pipeline on the P1 reference inputs in memory (E23 a); keep the label of each panel orbit. Discard everything else of that run.
3. Open each chunk file once; read the items of E25 into tables indexed by (orbit, row of E25, direction, precision). Run the checks E36 g to k, n and p. Release nothing before step 9.
4. Orbit identity (E24); reference class and lambda_ref, lambda_ns (E23); the sets (E29).
5. For every orbit and every X: the budget steps (E26), the scores and the verdicts of R1 and of R2 for k = 0 to 9 (E27); the chaos scores (E31); the stable verdict, detection time, outcome and censored time (E28).
6. Statistics and decisions in the fixed order H1, H2, H3, H4, H5, H6 on the primary rule and sets (E32, E34); each with its "not decidable" rule.
7. The extension and ROBUST flags, the gate and the second versions, the R2 version (E33).
8. The reported items T2, T9 to T11, T14 to T17 and the data of F1 to F6 (E31, E35, E37); the digests.
9. Write the tables file. Re-check the hashes of all inputs (I12). Then the figures if the extension provides them (P11); set the exit code.

E56. PP for HB [Test draw size and power calculation, PP for HB]. Only theta* and the Cal data enter; no test data exist.
 a. Optimism. For b = 1 to `b_opt`: the stream (optimism, b) draws |Cal| orbits with replacement from Cal listed in increasing orbit id; on the resample the sets are those of the drawn orbits (with multiplicity; drawn gate-set members count with multiplicity, none drawn means F4 holds, P51); C3 to C6 are run on the resample (the cost cap, the thresholds and the order of E54 unchanged) and give theta_b; if F is empty on the resample (which includes a resample with an empty set, where a share is undefined and no element is feasible, P49), that resample is skipped and counted; a set below `min_set` on a resample does not skip it (the resample is used as is; proposed, P66); the number skipped is reported and no limit on it is applied (P65). For A in {T_s, W2}: optimism(A) = the mean over the valid resamples, summed in increasing b, of [FR(theta_b; Cal set A) - FR(theta_b; resample set A)] (binary64). r(theta*, A) = FR(T_s; theta*) or FR(W2; theta*) on Cal; r_corr(A) = r(theta*, A) + max(optimism(A), 0). For R_W: the corrected counts by difference, r_corr(R_W) = [r_corr(W2) |W2| - r_corr(T_s) |T_s|] / |R_W| (Cal sizes), clamped to the unit interval (P52). The rule rate: p_rule(A) = r_corr(A) if r_corr(A) >= `rule_rate_floor`, else max(`rule_rate_factor` x r_corr(A), `rule_rate_floor`), for A in {T_s, R_W}.
 b. Strata and rates from Cal at theta*. The strata are T_s and R_W (W2 = T_s plus R_W). For each stratum S and each X in I_7 (also LE on the stratum T_s, because W2 contains T_s and the comparison of LE on W2 uses all its orbits, P52): p_X(S) = FR_X(S) at the matched budget of E53 (R_W by counts by difference, as in a); the shared share s_X(S) = (the rule false-regular orbits that are also false-regular under X) / (the rule false-regular orbits), and the value `shared_default` (the text of PP step 2) if the rule has none; the decided share d(S) of theta* (R_W by counts by difference). These are reported by source (panel, grid) as well; the pooled values are used.
 c. Model of one orbit of stratum S [PP for HB, step 3]. The rule is false-regular with probability p = p_rule(S). Given that, X is false-regular with probability s_X(S); given that the rule is not false-regular, with probability max(p_X(S) - s_X(S) p, 0) / (1 - p) (0 if p = 1); the comparators are independent given the rule outcome. The orbit is decided if the rule is false-regular; otherwise with probability clamp((d(S) - p) / (1 - p), 0, 1) (P53). Each simulated orbit uses nine uniforms, in the order: the rule, then the seven comparators in the order of I_7, then the decided indicator.
 d. Draw path. rho_r runs over `rho_path_start` + j x (the step), j = 0, 1, ..., up to `r_max` (the point `r_max` included); the count of points is derived from the keys. n_T(rho_r) = round(rho_r x `y_t`) and n_RW(rho_r) = round(rho_r x (`y_w` - `y_t`)), "round" half away from zero (P55); n_W(rho_r) = n_T + n_RW. A point is allowed iff n_T >= `n_t_min` and n_W >= `n_w_min`; points that are not allowed are listed with their sizes and are not simulated.
 e. Simulation. For each allowed point, `pp_runs` runs, run i with the stream (pp-hb, point, i): the orbits of T_s (n_T), then of R_W (n_RW) are drawn (c). Per set A and comparator: the counts n11, n10, n01, n00 (rule false-regular and X false-regular; rule only; X only; neither), a = n10 + n11, c = n01 + n11, and the decided count. The full decision succeeds iff for the 13 comparisons (the six of I_6 on T_s; the seven of I_7 on W2, counts summed over the two strata): m = n10 + n01 >= 1, the exact one-sided p-value P(Bin(m, 1/2) >= n01) <= `alpha_hb` (decided by exact integer arithmetic, a critical-value table per m), c >= 1 and a <= `rho_hb` x c (exact); and the coverage condition holds on both sets: the decided count of A >= `c_min` x |A| for A = T_s and A = W2 (the meaning of "decided" is the rule's, P57). Power(point) = successes / `pp_runs`, reported with its Monte Carlo standard error sqrt(power (1 - power) / `pp_runs`). rho* = the smallest allowed point whose power is >= `p_hb` (exact comparison); the targets are n_T = ceil5(`y_t` x rho*) and n_W = ceil5(`y_w` x rho*), where ceil5(x) is x rounded up to a multiple of `ceil_step`. If no allowed point reaches `p_hb`, the targets are the cap `y_t` x `r_max` and `y_w` x `r_max`, the cap flag is set and the expected power at the cap (the point `r_max`) is recorded; if no point is allowed the outcome is "no allowed point". The study then runs anyway (NEGATIVE allowed; preregistration).
 f. Type-I check. At rho* (or at `r_max` when the cap binds), for each X in I_7 in turn (P54): the same simulation with the rule rate of both strata set to the rate of X in that stratum (p = p_X(S)), all other quantities unchanged; recorded: the rejection rate of the joint decision, the rejection rate of the single comparison of X, and the maximum over X of the joint rate. The oracle requires the joint rate to be at most `alpha_hb` plus 3 standard errors (O16).

E57. PP for HC [PP for HC; Hypotheses, HC]. Cal orbits with rho in {C, R} and K > 0 (the gate and all K = 0 orbits are out), not dropped; the voting set V* of theta*, the budget b_P. The Float64 votes of an orbit are the decided verdicts c_X(b_P), X in V* (not filtered by stability: the plain label of HC; P64); n_C and n_R are their counts; the plain label is chaotic if n_C > n_R, regular if n_R > n_C, and a tie (including no decided vote) counts as a failure; f = 1 iff the plain label differs from rho (a tie is a failure); the score s_I = 1 - |n_C - n_R| / (n_C + n_R), and 0 if n_C + n_R = 0. AUC_I_cal = the area under the ROC curve of s_I for f (Mann-Whitney, ties one half, D89 E31) over these orbits, reported with the numbers of failures and non-failures (and by source); AUC_I_used = 0.5 + `auc_shrink` x (AUC_I_cal - 0.5), the key being the multiplier of the shrinkage row of the register. AUC_P = `auc_p`. True difference = AUC_I_used - AUC_P. Binormal pairs: for an AUC value A the shift is d(A) = sqrt(2) Phi^{-1}(A) (Phi^{-1} the inverse of the normal distribution function; A must lie in the open unit interval, else refuse); failures draw from the normal with mean d and variance 1, non-failures from the normal with mean 0 and variance 1; the two predictors are independent. Draw order inside one run (one stream per run, E55): first the n_f failure scores of the predictor I, in index order, then its n_n non-failure scores, then the n_f failure scores of the predictor P, then its n_n non-failure scores; each score is its mean plus one normal variate, one inverse-function call on one uniform per variate. Hanley and McNeil variance of an AUC A with n_a failures and n_n non-failures: Q_1 = A / (2 - A), Q_2 = 2 A^2 / (1 + A), var(A) = [A (1 - A) + (n_a - 1)(Q_1 - A^2) + (n_n - 1)(Q_2 - A^2)] / (n_a n_n); no key in the bibliography; a standard result, defined here in full (P61). For n_f in the list `nf_start`, `nf_second`, ... (step their difference) up to the search cap, the smallest listed value that is at least the worst-case deliverable failures below, rounded to the step (a stated module bound, P67); the search does not stop at the expected deliverable number (P56): n_n = `nonfail_per_fail` x n_f; `pp_runs` runs, run i with the stream (pp-hc, n_f, i), each draws the two score samples of the two predictors, computes the empirical AUCs A_I and A_P, Delta = A_I - A_P and SE = sqrt(var(A_I) + var(A_P)) with the formula at the empirical AUCs (independence, no covariance term; P64); the decision succeeds iff Delta >= `delta_c` and Delta - `z_one_sided` x SE > 0. Power(n_f) = successes / `pp_runs` with its standard error. Target n_f = the first listed n_f with power >= `p_hc` (exact), recorded with its power and standard error, or "not reached" (then the power at the cap is recorded). Deliverable failures: floor(`d_expected_total` / (1 + `nonfail_per_fail`)) for the expected size of D and the same with `d_worst_total` for the worst case (both reported). The power at the expected deliverable number is recorded separately (simulated as one more point when that number is not on the list, with its own stream unit). If the target is "not reached" or exceeds the expected deliverable number, the flag "underpowered" is set (preregistration: HC is run and reported underpowered with the power of A1; no round is added).

### Algorithm (amendment)

Order of work for `calibrate`. No step depends on a result of a later step.

1. Dispatch and checks (E46, E47, E48): read the preregistration and the parameter table, apply the hash rule and the table checks, read the p2 and P1 manifests, the panel file and the p2 table; take the SHA-256 of every input file.
2. Open the p2 chunk files and the P1 chunk files once; read the items of E49 and E51 into tables indexed by orbit and item; run the identity and recorded-step checks.
3. Relabelling and counts (E49), Cal and the sets (E50).
4. Verdicts for every orbit of Cal (E51); the stability evidence per orbit, indicator and depth.
5. The search space (E52) and the cost model (E53); C3 for all of Theta (data-parallel over theta); C4 to C8 (E54).
6. If theta* exists: the optimism bootstrap (data-parallel over resamples, each with C3 to C6 on the resample), the strata and rates (E56 a to c), the simulations of the draw path (data-parallel over runs), the type-I check (E56 d to f); the PP for HC (E57).
7. Assemble the record and the tables file (E58); compute the record hash; re-check the input hashes (E48 j); write the files.
