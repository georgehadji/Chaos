# Spec: integrator-catalog

Status: approved at the stage 01 checkpoint, 2026-11-06 (D111), with open points P1 to P17 settled as proposed. Library layers: Integrators, with the Hamiltonian-flow systems it needs added to Systems. Milestone M5 (`_config/build-order.md`, row "M5 P3", entry "integrator catalog"). No Julia type, function or file names appear outside the Compute and Oracle sections (Pattern 10). "Derived" marks a statement derived while drafting; "drafting check" marks a throwaway numerical check run in the session scratchpad (Python, mpmath, scipy; not a source, not citable, to be reproduced at stage 02 and 04). "Read" means the cited text was opened and the quoted equation or table found in it (location in Sources). No coefficient is copied into this spec: tables are named by paper and table or equation number, and stage 03 copies them from the source.

## Scope

- Catalog rows (`_config/catalogs/integrators.md`): S1 to S9 and S11 to S13 (explicit splitting for separable H = T(p) + V(q)), P1 to P3 (near-integrable H = A + eps B), G1 to G3 (implicit and nonseparable), R1 (non-symplectic reference orbits; R2 deferred), the section "F. Variational equations" (tangent dynamics by the same splitting, SkokosGerlach2010) and the section "G. Checks every integrator must pass" (turned into the acceptance criteria below).
- Out of scope, by the Phase column: S14 (processed methods, catalog only), G4 (Pihajoki, catalog only), R3 (Bulirsch-Stoer, catalog only), N1 to N10 (N-body family, M7 adapters), and "F2. Modified (shadow) Hamiltonian" (research line R2, module Shadow, M7). Adaptive or variable step sizes are out of scope (fixed step; the variable-step content of CalvoSanzSerna1993a is not used). The Kepler drift flow (exact flow of the Keplerian part A, Wisdom-Holman type) is out of scope: it belongs to N1 (M7); P1 to P3 are tested with A = free drift.
- Test flows (`_config/catalogs/systems.md`, section B). In scope, because the integrators cannot be tested without systems with exact solutions: F1 (harmonic oscillator, n degrees of freedom), F2 (Kepler problem, planar, exact solution), F4 (pendulum; the near-integrable form H = p^2/2 - eps cos q is the test problem of the P rows, as in LaskarRobutel2001), and one test-only nonseparable Hamiltonian T1 (Tao2016, Sec. II A, H = (Q^2 + 1)(P^2 + 1)/2) for G3. Out of scope: F3 (own module `henon-heiles`, which uses this module), F5 (optional), F6, F7 (M7, M8). No catalog row of the test flows has a module of its own in the build order (F1, F2, F4 are not assigned); see open point P1.
- Prerequisites: Foundation, Systems (maps verified; the flow side is new, this module adds it, see Inconsistencies (a)) and Tangent (tangent-core, verified). Layering (`_config/architecture.md`): Integrators imports Foundation and Systems only.
- The module supplies, per method: one step of size tau (either sign), the tangent step (action on a frame of deviation vectors) by the same splitting, the stage and force-evaluation counts, and the health status of the nonlinear solve (implicit methods); per test flow: the partial flows of the splitting, the energy and other first integrals, and the exact solution where it exists. It does no renormalization of deviation vectors and no indicator work (Tangent, Lyapunov and Indicators own those).
- Dimension: 2n, 1 <= n <= 100 (F5 is optional and later). Domain: any finite state; non-finite input gives non-finite output for the explicit methods (as the verified maps); an implicit step whose nonlinear solve fails reports a failure status and never a silent value (Algorithm item 9).
- Method set. Every row listed above has a read source for its equations and coefficient tables (Sources); rows without one are in the subsection "Deferred rows" below and have no criterion in this spec.

### Deferred rows

The catalog Status stays `planned` for these; a later run (an amendment of this spec) picks them up when the source is supplied. No acceptance criterion depends on them.

- S10 (Blanes-Moan SRKN): BlanesMoan2002 not read.
- R2 (high-order explicit RK reference): HairerNorsettWanner1993 not read, and the second solver named by the catalog (Verner's pair) has no key. Criterion 20 and the oracle for R2 are removed.
- The parts of G1 and G2 that need HairerLubichWanner2006 (not read): the Newton option of the nonlinear solve, the closed-form Gauss coefficients and the symplecticity condition on the coefficients, and the statement that Gauss methods preserve quadratic first integrals (removed from I6 and criterion 14 for G1 and G2). What stays: the Gauss methods as the s-stage, order 2s, symplectic and symmetric Runge-Kutta methods that Hairer2008 Sect. 2 states them to be, with coefficients computed, not copied.
- Jet transport (Taylor series in the initial conditions) for reference tangents: TaylorIntegrationJL and BenetSanders2019 not read; the reference tangent is a finite difference of reference orbits.
- The closed-form exact solution of F2 by Kepler's equation (catalog source HairerLubichWanner2006 not read; F2 is used here only as its Hamiltonian): the truth for F2 comes from the reference orbits of oracle O1 and from exact first integrals.
- CandyRozmus1991 and Suzuki1990 (not read): no row depends on them (S5 and S7 have other read sources).

T1 (test-only, nonseparable): Tao2016 Sec. II A. T2 (test-only): Henon-Heiles H = (p_1^2 + p_2^2)/2 + (q_1^2 + q_2^2)/2 + q_1^2 q_2 - q_2^3/3 with q_1(0) = 0, q_2(0) = 0.3, p_2(0) = 0.2 and p_1(0) > 0 from H_0 = 1/8: the system of the Brouwer experiment of Hairer2008 Sect. 2 ('Numerical experiment'); the module henon-heiles (F3) will own this system later, T2 is here only for criterion 15.
19. Brouwer's law and round-off (Hairer2008). Round-off of one step as a mean-zero random variable with variance proportional to eps^2 gives an energy error growing like the square root of time (Hairer2008 Sect. 1, p. 232); with compensated summation E|H(y_n) - H(y_0)| = C eps h^(1/2) t^(1/2), t = n h (Hairer2008 Sect. 4, displayed formula after Eq. (4.2), p. 239); the systematic local error of rounded coefficients is Eq. (4.1), the modified Hamiltonian Eq. (4.2). Compensated summation adds the increment to the state in higher precision so that the round-off of the update is reduced by a factor h (Hairer2008 Sect. 2, pp. 233 to 234, there after HairerLubichWanner2006 Sect. VIII.5, not read; this spec uses only that property: the sum is carried as a value and a correction term per component). Observations used for tolerances: explicit compositions of Stormer-Verlet follow the square-root law (Hairer2008 Fig. 2.1); a standard implicit Runge-Kutta implementation adds a linear growth (Fig. 2.1) that only the two remedies of Sect. 3 together remove (Fig. 3.1, 'grk-co-ex'); with 1000 random starts the mean error is zero to sampling error, the standard deviation grows like n^(1/2) and the end values are normal (Figs. 5.1, 5.2, Table 5.1); the law needs the orbit to stay in a compact set (Sect. 5, text after Table 5.1), and the Runge-Lenz vector of the Kepler problem has linear error growth even in exact arithmetic (Sect. 4, last paragraph).

## Algorithm

1. Generic splitting stepper. One step of size tau (positive or negative) runs a coefficient table of k stages (c_i, d_i), i = 1..k: drift with weight c_i, then kick with weight d_i (Yoshida1990 Eq. (2.8)), for a flow that provides the exact partial flows. A table declares: stage count, whether it is palindromic (symmetric), its nominal order, and its source. Stages with weight 0 are skipped. Adjacent kicks of consecutive stages, d_i of stage i together with c-free neighbours, may be merged so that one force evaluation serves two half steps; the result must equal the unmerged result up to rounding, and the force-evaluation count per step is part of the table's metadata. The stepper is written once; adding a method is adding a cited table and its order test. Tables: S1 (two orderings), S2 (drift-kick-drift and kick-drift-kick), S3, S4, S5, S6 (4, 6, 8), S7 (4, 6, 8), S8, S9, S11, S12, S13.
2. Composition builder. Input: a symmetric order-2 table (S2) or a higher table, and a rule: the triple jump (Equations item 5) or the 5-piece Suzuki rule (item 7). Output: a table. The builder reproduces the closed forms: the 4th order triple jump of leapfrog equals Yoshida1990 Eq. (2.11) and Omelyan2002 Eq. (8); the builder runs in the element type with the real roots computed in that type. Resulting stage counts for orders 4, 6, 8: triple jump 3, 9, 27 leapfrog pieces; Suzuki 5, 25, 125 (derived, drafting check). Rows S5, S6, S7 are produced by the builder and cross-checked against the listed closed forms.
3. Tabulated high-order schemes (S8 PEFRL by its parameters, S11, S12, S13, S9): the table is the source's table; no search for coefficients. Palindromic tables store the first half and mirror it. Constants are held in the element type: algebraic constants (cube roots, square roots) computed in that type; decimal constants of the source converted from the printed digits. A tabulated constant carries the source's digit count d_tab; for any run in an element type with eps_T below 10^(-d_tab) the usable accuracy floor is 10^(-d_tab) and criteria use max(eps_T, 10^(-d_tab)) (Yoshida1990: 15 digits; KahanLi1997: 20 digits; Blanes2013 and LaskarRobutel2001: 40 digits; Omelyan2002: 16 digits). Polishing tables to full working precision by Newton iteration on the order conditions is not done (open point P10).
4. Near-integrable stepper (P1 to P3). The same table machinery with the flow split as H = A + eps B, tables of (a_i, b_i) where a_i weights the exact flow of the integrable part A (free drift in the tests) and b_i the exact flow of the perturbation B (a kick of eps grad V(q)). Classes: SABA_n, SBAB_n (LaskarRobutel2001 Table I), ABA864 and ABAH864 (Blanes2013 Tables 3 and 4). The ABAH tables are used with an exact B flow in this module (their purpose with an approximated B flow, Blanes2013 Eq. (24), arises only for momentum-dependent perturbations, out of scope). Corrector (P2): the extra kick before and after, with the potential |grad V|^2 times a coefficient from LaskarRobutel2001 Table II times tau^3 eps^2 / 2 (Equations item 11); the flow must supply grad |grad V|^2 for the kick.
5. Implicit midpoint and Gauss (G1, G2). Stage equations of Equations item 13. Solver: fixed-point iteration from the explicit-Euler guess; contraction needs h L max_i sum_j |a_ij| < 1 (derived, L a Lipschitz constant of the vector field on the orbit region). Stopping rule (Hairer2008 Sect. 3, 'Iteration until convergence'): iterate until the largest stage increment is exactly 0 or is no longer smaller than at the previous iteration (the increments then oscillate at round-off); the update uses f at the stages of the previous iteration. Acceptance after the stop (derived, proposal): the step is accepted when the final increment is at most 8 eps_T max(1, |Y|_inf); otherwise, or when 50 iterations pass without a stop, or a value is non-finite, the step is flagged as failed, the orbit stops there, and no silent value is returned. Coefficients: the machine-number part and the small remainder of Hairer2008 Eq. (3.1), both applied in the stages and the update; optional compensated summation of the update (item 11). Stages and the stop test are computed in the element type of the state; the number of iterations of the last step is reported. Solving to the round-off level matters because the symplecticity of the step holds for the converged stages (Hairer2008 Sect. 3, first remedy).
6. Tao's method (G3). State in the extended space (q, p, x, y), initial value (Q0, P0, Q0, P0); one step: Strang composition of the three partial flows (Equations item 14), higher order by the triple jump with the corrected exponent (Equations item 5, Inconsistencies (d)); output the physical pair (q, p) (the pair (x, y) is also available). Input: omega (binding parameter), order, step. The nonseparable H and its gradient are supplied by the flow (T1 in the tests). The method is symplectic in the extended space, not in (q, p) (Tao2016, Sec. I).
7. Taylor reference (R1). Taylor series method of order p with the step from the last coefficients (Equations item 15), run in 256-bit arithmetic at a working precision of at least 256 bits and a requested truncation error of at most 2^-200 on a single step, as the truth generator for the tests of this module (reference orbits) and the reference tangent by a finite difference of reference orbits (jet transport deferred). R1 is a reference and not a symplectic integrator: no symplecticity claim.
8. R2 is deferred (Scope).
9. Tangent (variational) integration (catalog section F). For each method the tangent step multiplies the deviation frame (2n x k, k >= 1) through the elementary Jacobians in the order of the stages (Equations item 17), without forming the 2n x 2n matrix when k < 2n; cost per step is the stage count times O(n^2 k) for general Hessians, O(n k) for diagonal ones (F1, pendulum chains). Implicit methods: the frame is advanced by solving the linear system obtained by differentiating the converged stage equations. Tao's method: the frame lives in the extended space (4n components); its initial value and projection to the physical space are not specified by the source (open point P11). The module returns the frame; renormalization is the caller's.
10. Health and failures. An invalid table (a sum condition violated beyond the bound of criterion 1, a non-palindromic table declared symmetric, a stage count of 0) is rejected at construction, not at the first step. Non-finite input propagates (explicit); the implicit solver reports failure (item 5). No method raises an error inside a kernel (GPU rule of `_config/architecture.md`, "Compute"): failures are recorded in the status and read after the run.
11. Energy and first integrals. The flow reports H, and for F2 the angular momentum and the Runge-Lenz vector, in the element type. Compensated summation (Equations item 19) is an option of the stepper for the position and momentum updates (a value and a correction term per component); default off (open point P12).

## Invariants

Hold for every step of the methods listed, in the element type T (rows and exceptions named):

- I1: symplecticity of the one-step Jacobian M, M^T Omega M = Omega, for S1 to S9, S11 to S13, P1 to P3, G1, G2 (to the solver tolerance for G1, G2), and for G3 in the extended space with the extended form (not in the physical (q, p) block). R1 is exempt.
- I2: time reversibility S(tau) S(-tau) = id for the symmetric tables (palindromic, Yoshida1990 Eq. (3.4)), G1, G2 (to the solver tolerance) and G3 Strang (symmetric in the extended space); S1 and the other non-palindromic tables are not symmetric and instead satisfy: the adjoint of S1 (A then B) is S1 (B then A).
- I3: coefficient consistency: sum c_i = sum d_i = 1 (Yoshida1990 Eq. (2.9); for the palindromic compositions sum gamma_j = 1, KahanLi1997 Eq. (4); for the near-integrable tables sum of the A weights = sum of the B weights = 1, LaskarRobutel2001 text after Eq. (8)); palindromic symmetry c_i = c_{k+1-i}.
- I4: the one-step map reproduces the exact flow of the harmonic oscillator through the nominal order in the Taylor series of the step matrix (criterion 2).
- I5: energy error bounded, no secular drift, for regular orbits; the round-off part grows like t^(1/2), Brouwer's law (Hairer2008 Sect. 4, formula after Eq. (4.2)).
- I6: quadratic first integrals: the angular momentum of F2 and the energy of F1 are preserved to round-off by every explicit splitting that is a product of the elementary flows (drift and kick each preserve them exactly, derived). For G1 and G2 deferred (Scope).
- I7: the tangent step equals the derivative of the one-step map (criterion 9), and a product of n tangent steps equals the derivative of the n-step map; the tangent step is symplectic (I1).
- I8: negative step: S(-tau) is the inverse of S(tau) for a symmetric table; for a general table it is the adjoint table's step at tau.
- Error budget: B(n) of the Acceptance criteria preamble for orbit comparisons across element types and backends; eps_T the machine epsilon of T, for double-double the effective value measured at the precision spec's check (not less than 2^-104).

## Compute

Policy: `_config/architecture.md`, "Compute" (decision D17). Machine: GTX 1050 3 GB, compute capability 6.1, weak binary64 throughput (risk K15); CI has no GPU.

- Data parallel, GPU candidates: ensembles of independent orbits (grids of initial conditions, parameter sweeps) of the explicit splitting methods (S1 to S9, S11 to S13, P1 to P3), whose step is a fixed sequence of isbits operations; one kernel serves CPU and GPU. The module ships GPU as default only if the cross-backend test passes and the tangent-core style benchmark shows a GPU win (D25).
- Implicit methods (G1, G2): the iteration count differs per orbit (divergence inside a warp) and the failure status is per orbit; the kernel is attempted but a GPU win is not assumed; fallback to CPU with the existing reasons. Double64 is attempted on the GPU and falls back with "kernel does not compile for the element type" if it does not compile; BigFloat is CPU only. R1 (Taylor, BigFloat) is CPU only, single long orbits; it is a verification and reference tool, a weak dependency (package extension) loaded under the verify environment like CUDA, not by the library (open point P3).
- Single long orbits: CPU. The stepper cost per orbit step is the force-evaluation count of the table (metadata).
- Memory per orbit (structure-of-arrays), numbers per orbit: state 2n (Tao: 4n); tangent frame 2n k (full matrix 4 n^2); implicit stages s 2n plus the Jacobian workspace. For F1 and F4 at n = 1 to 3 these are tens of numbers. Chunk sizes derive from free memory at run time (policy).
- Reproducibility: seeds keyed by orbit id, never by thread or device; the CPU result of orbit j is bitwise identical with 1 and with N threads; the GPU-vs-CPU bound is not bitwise.
- CPU-vs-GPU agreement: the bound B(n) of the Acceptance criteria preamble, in units of eps_T of the element type, for n <= n_H, maximum over the ensemble. Longer runs (chaotic flows) are compared at estimator tolerances owned by the Lyapunov and Indicators specs.
