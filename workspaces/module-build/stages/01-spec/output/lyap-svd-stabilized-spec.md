Gives the finite-time singular-value exponents lambda_i^SVD(n) = (1/n) ln sigma_i(Y_n). Dieci1997 has been read: its only SVD statement is one sentence at the start of its Section 3 (p.8) and it contains no discrete SVD algorithm, so nothing is cited from it for L9. Therefore: the algorithm is DERIVED and fully specified for d = 2 (all M2 systems are 2N = 2, diagnostics Scope); for general d only the contract and invariants are written (Algorithm item 5, "Held") and the algorithm is held until the owner supplies a full text (D30). A request with d != 2 is rejected before any work (AC12).
- Out of scope: the single-vector, two-trajectory and Householder estimators; covariant vectors; singular vectors as outputs.

## Algorithm

The estimator is the GS estimator with k = d = 2 and the variant RGS (g = 1, GS Algorithm items 1 to 5, including the breakdown rule) plus one more per-orbit scalar c. It is a reducer of the tangent stream (tangent-core "Contract"); it reads the point and W only, so the wrapped state of D28 needs no change (GS I7).
1. At handoff j: factor W_j = Q_j R_j (RGS), replace W by Q_j, update S_1, S_2 with the compensated sums of GS Algorithm item 2, and update c by V5 using the S values of window j-1 (before adding window j).
2. Output at every handoff of the study's cadence: lambda_i^SVD(n) from V6 divided by n (i = 1, 2) and, because it is free, lambda_i^QR(n) = S_i / n and c_n. The QR family output is the GS output, bitwise (AC3).
3. c is accumulated without compensation. Why: an increment (r12 / r11) exp(S_2 - S_1) is at most ‖M‖^2 exp(S_2 - S_1) in size (r12 <= ‖w_2‖ <= ‖M‖ and, for det 1, r11 >= 1/‖M‖; ‖M‖ the window norm); for chaotic orbits S_1 grows linearly so they decay geometrically, and for regular orbits S_1 grows like ln n so they decay like n^-2 (K = 0: exp(S_2 - S_1) = 1 / (j^2 + 1) with the frame of V9b). The sum of absolute increments converges, so the rounding error of a plain running sum is a fixed multiple of eps and does not grow with n. Tested by AC3(c).
4. Recorded: estimator family, d = k = 2, factorisation variant RGS, `orthogonality_tol`, tau, precision (provenance additions and value list: GS Algorithm item 3, (D30)).
5. Held (general d, no algorithm written). Contract for a later algorithm: input the same stream and the same Q_0; output lambda_i^SVD(n), i = 1..d, from a computation that never forms Y_n by plain multiplication; each ln sigma_i within theta_sum (GS G13) of the 512-bit reference at n <= 12; sigma_i sigma_{d+1-i} = 1 to theta_sum for symplectic maps while QR pairs only asymptotically (diagnostics I4, I5): the N >= 2 discriminator; degenerate spectra (Y5 rotation blocks, exponents 0, 0) must not raise (V3). These three are criteria H1 to H3 of stage 02 once the owner releases the algorithm; none is scored in M2.

## Invariants

- I1 sigma_1 >= sigma_2 > 0, lambda_1^SVD >= lambda_1^QR (V7 lower bound), equality up to rounding only when c_n = 0 and u negligible.
- I2 Basis independence in exact arithmetic: lambda_i^SVD(n) depends on the orbit and n only; not on tau, on the variant, or on Q_0 (V4: the singular values of Y_n). Differences between runs with different tau or frames are round-off, bounded by theta_sum.
- I3 Sum: lambda_1^SVD + lambda_2^SVD = (S_1 + S_2) / n, so |sum| <= theta_sum for symplectic maps (GS G9).
- I4 V7 holds at every handoff to rounding: the pair (lambda^QR, c_n) determines the SVD exponent.
- I5 Everything stays finite however large S_1: no product of window matrices is formed; the largest intermediate quantity is F = O(1 + c^2).
- I6 Orbit, thread, chunk and backend independence, zero allocation after warm-up, lifted coordinates never wrapped: GS I5, I7, tangent-core I5, I8.

## Amendment D35 (2026-10-14)

Source: the stage 02 test plan of this slug (ambiguity on AC3(c) and AC5) and the measurements in `scratchpad/m2/batch-b-bound-table.md` (Julia 1.13.1, a throwaway estimator written from the Batch B contract, never in the repo; to be reproduced at stage 04). Criterion numbers are unchanged.

### Criterion 3(c): the class of orbits, not the sample

The convergence of c rests on Algorithm item 3: the increment of c at handoff j is at most sigma(K)^(2 tau) exp(S_2 - S_1) taken before the window (r_12 / r_11 <= ||M^tau||^2), which decays only where S_1 grows. The spec scored every orbit with S_1(500) < 25 "as the K = 0.5 case" with the constant 0.02, which is wrong for two reasons: the constant was taken from four shear frames, and orbits near elliptic points or accelerator modes (S_1 stays near 0) have increments that do not decay at all, so c does not converge and no rule of this kind can hold for them. Measured on 1800 orbits (K in {0.5, 2, 5, 2 pi}, tau in {1, 2, 4}; 200 starts for K = 0.5 and 2, 100 for K = 5 and 2 pi; n = 500 against n = 1000): 744 orbits have S_1(500) < 25 and 129 of them exceed 0.02; by class of S_1(500): below 0 (9 orbits) up to 9.9 relative change, [0, 2) (27) up to 1.45, [2, 5) (312) up to 0.41, [5, 25) (396 orbits) at most 0.0261 (3 above 0.02), at least 25 (1056) exactly 0. The corrected rule, with the class defined by S_1(500) and applied to every orbit of the panel:

- S_1(500) >= 25: abs(c_1000 - c_500) <= 8 eps max(1, abs(c)) (unchanged; the late increments are absorbed).
- 5 <= S_1(500) < 25 (shear-dominated: K = 0.5 regular orbits, slow chaotic orbits): abs(c_1000 - c_500) <= 0.06 max(1, abs(c_500)) (algebraic convergence like 1/j^2; the worst of the 396 orbits is 0.0261, margin 2.3). The constant 0.06 is a proposal.
- S_1(500) < 5 (near elliptic points and accelerator modes): no convergence claim; the value of abs(c_1000 - c_500) / max(1, abs(c_500)) is reported with the class counts, not scored. The orbits are not dropped from the panel: criteria 3(a), 3(b), 4 and 7 hold for them.

The per-orbit bound abs(c_n - c_m) <= ((n - m) / tau) sigma(K)^(2 tau) exp(-2 s_min + |S_1 + S_2|), s_min the minimum of S_1 over the handoffs in [m, n) (|S_1 + S_2| taken as 2e-12 in the measurement), holds on all 1800 orbits (largest ratio of the change to the bound 0.104) and is informative only where s_min is large; it is the derivation of the classes, not a scored criterion.

### Criterion 5: the orbit

The spec's "one seeded orbit" does not determine the control: the plain Float64 product keeps sigma_2 as long as 1/sigma_1 is above its rounding floor (about eps sigma_1), so the gap abs(ln sigma_2^naive - ln sigma_2^ref) exceeds 10 only for strongly stretching orbits. Measured on 60 seeded starts at K = 2 pi, n = 20 (ln sigma_1(20) from 14.2 to 31.9, median 24.0): the gap exceeds 10 (or the plain product has an exactly zero smallest singular value, gap infinite) for every orbit with ln sigma_1(20) >= 24.9; among orbits with a finite gap of 10 or less the largest ln sigma_1 is 24.25, and the smallest ln sigma_1 among orbits with gap above 10 is 20.6 (an exactly zero singular value). The control therefore uses an orbit with ln sigma_1(20) >= 25, the first one in the seeded sequence of starts (21 of the 60 qualify); the scratch orbit of the spec (ln sigma_1(20) = 25.8, gap 13.3) is of this kind. The overflow statement (non-finite plain product before n = 700) is unchanged.
