# Test plan: lyap-two-trajectory

Spec: `workspaces/module-build/stages/01-spec/output/lyap-two-trajectory-spec.md` (D30: own per-orbit loop, no reducer chain), as amended by its Amendment D35 (T5a, T6a, criterion 4). The bounds below are pointers to the spec; the plan derives nothing. API contract: M2 Batch B `api-batch-b.md`, final (D34); names tested: `propagate_shadow`, `propagate_shadow_orbit`, `separation`, `displaced`, `Benettin`, `effective_eps`, and the Batch A names `propagate`, `forward`, `initial_deviations`, `StandardMap`, `WrappedStandardMap`, `LinearSymplecticMap`, `torus_state`, `exact`, `NumericalHealthError`. Tests: `test/lyap-two-trajectory/runtests.jl` including `l2_helpers.jl`, `l2_analytic.jl` (AC1 to AC5), `l2_sweeps.jl` (AC6 to AC9), `l2_runtime.jl` (AC10 to AC12). Helpers and test maps are prefixed `l2_` / `L2_`; nothing in `src/`, no top-level call into `Chaoslab.Lyapunov` (a missing module errors the testsets, not the run).

Conventions. Element types Float64 and Double64 (D24); tolerances in units of `effective_eps(T)` (Float64 eps, Double64 2^-100). Constants of the spec in one place (`l2_helpers.jl`): B_S(n) = 8 eps (n + G_first) + 16 abs(K) n^2 eps (`l2_BS`, `lyap-benettin` S3 as amended; K = 0 for the linear maps), Psi_n (`lb_Psi` of `test/lyap-benettin/lb_psi.jl`, included once; `l2_Psis` for a vector of starts), the pathwise bound of T5a (`l2_pathbound`); sigma(K) (`l2_sigma`), E_nl = abs(K) sigma d0 / sqrt 2 (`l2_Enl`), E_ro = (abs(K) + 4) M_state eps sigma / d0 (`l2_Ero`), Delta_2T = 2 (E_nl + E_ro) (`l2_D2T`), the validity limits of T5 (`l2_valid`), d0* of T8 (`l2_d0star`). References: 256-bit BigFloat (`l2_big`), exact BigInt Fibonacci products for the cat map. Seeds: base 20261012 (`numerics-defaults.toml`) plus offsets 25000 to 25999 (`L2_BASE = 20261012 + 25000`), `l2_seed(ac, sub) = L2_BASE + 50 ac + sub` with sub < 50 (AC1 is 25050 to 25099, AC6 25300, AC12 25600; all inside 25000..25999); none of the Batch A offsets below 20000 are reused. Orbit ids are the positions in the start vector; the seeded direction of orbit j is the first column of `initial_deviations(seed, j, Val(2), Val(1), T)`.

Test-side tools: `l2_X` (Benettin run on the identical orbit and direction: the L1 value X), `l2_X2` (`propagate_shadow`, the final record read as `sum + comp`), `l2_Fault` (:collapse, :inf_ref, :inf_shadow, :inf_both: a map that collapses the pair or produces a non-finite point at a chosen handoff on a flagged orbit), `l2_Boom` (throws if called: proves a pre-launch rejection), `l2_Plain` (wrapped system whose `separation`/`displaced` are the plain difference; its methods exist only when `Chaoslab.Lyapunov` is defined; used by AC4 as the discriminating double), `l2_regular_starts` (S7 screening of the regular class by a Benettin run; replaced starts counted), `l2_Gfirst`, `l2_Mstate`.

## Deviations and ambiguities (owner decisions needed)

A1. Reporting. Large tables (AC6 grid points outside the T5 limits, AC8 minima, AC9 ratios) are printed with `@info`, never silently dropped.

A2. Final record. `finals[j][1]` carries `(n, sum, comp, X2, d_prev)`; the tests read n X2 as `sum + comp` (compensated) and X2 as the field `X2`.

A3. Resolved by `lyap-two-trajectory` Amendment D35. The stage 02 draft used slack factors (4 for X >= 0.1, 1 + 4 sqrt(n) for X < 0.1) because Delta_2T alone is exceeded by sticky and neutral orbits; the spec now carries the pathwise form T5a/T6a with the amplification sum Psi_n, and the tests use it without slack. The measured gap, the realized ratios and the open points are in the spec amendment. The T8 hierarchy (AC7, AC8 U-shape and Double64 improvement) is unchanged and has no slack.

A4. AC9 control is T7 as printed: the cap is X2 <= ln(pi sqrt 2/d0)/tau; the realized deficit is checked for the 50 starts (all have X >= 1.1).

A5. Resolved by `lyap-two-trajectory` Amendment D35. The estimator calls the system's `separation` hook and rejects a run whose initial separation lies outside [d0/2, 2 d0] before any work, so the plain-difference control is observed as a rejection (kind "separation", step 0), by the agreement of the double away from the boundary, and at hook level; the exponent ln(2 pi/d0) is not observable through `propagate_shadow` by design.

A6. AC5. A reducer-less stream (`propagate` with no estimator) overflows W after about 640 steps at K = 2 pi and is not used; the Benettin run (which renormalises) is the L1 comparison.

A7. AC12. At n = 1e5 and K = 5 98 of the 100 lifted starts have E_ro > 0.5 (|x| ~ 1e7 leaves no resolution at d0 = 1e-8; spec open point P6, unchanged). The test reports these points, allows only a "separation" health error, and tests the T5a bound for the two valid starts; the lifted run at n = 1e3 (all 100 starts valid) keeps the check from being vacuous. Wrapped mode is tested at both n. An earlier draft of this test paired the L1 value of a single-start run (orbit id 1, hence a different seeded direction) with the shadow run of start j; for neutral orbits that mismatch gives an offset of order 1/n independent of d0, which is a test error and is removed by the one L1 run over all starts.

## Package-suite size

Sample reductions for the 3 minute budget: AC5 Double64 20 starts (spec 100 for both types); AC6 at n = 1e4 only for K = 0.5; AC12 lifted at n = 1e5 is tested for the starts that stay valid (2 of 100) and reported for the rest. The full sizes go to stage 04 `verify/`.

Time. The suite was run against a throwaway stub of `Chaoslab.Lyapunov` (scratchpad, not in the repo) that allocates heavily. Measured on that stub, one file per process on a shared machine, 4 threads: AC1 to AC5 1 min 42 s, AC6 to AC9 1 min 38 s, AC10 to AC12 1 min 32 s (includes compilation). The package total is therefore about 5 min on the stub, which has no zero-allocation kernel; the real implementation should be several times faster, but the 3 minute budget is not proven. Stage 03 must time the real suite and report. If it is over, cut in this order: AC12 wrapped n = 1e5 to 50 starts, AC6 K = 0.5 at n = 1e4, AC7 200 starts to 100.
