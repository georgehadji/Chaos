# Paper

Turn accepted study results into one manuscript per run.

## Task Routing

| Task Type | Go To | Description |
|-----------|-------|-------------|
| Outline | `stages/01-outline/CONTEXT.md` | stage 01 |
| Draft | `stages/02-draft/CONTEXT.md` | stage 02 |
| Review and revise | `stages/03-review/CONTEXT.md` | stage 03 |
| Finalize | `stages/04-finalize/CONTEXT.md` | stage 04 |

| Resource | Location | Contains |
|----------|----------|----------|
